
  # Lovcal Marketplace App

  This is a code bundle for Lovcal Marketplace App. The original project is available at https://www.figma.com/design/BpskXIPKiLYCC6nb6nSsC6/MonCadeauLocal-Marketplace-App.

## Running the code

Run `npm i` to install dependencies.

Run `npm run dev` to start the development server.

## Quality commands

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run format`
- `npm run format:check`

  ## Supabase (MVP database)

  1. Create a Supabase project.
  2. Run [`supabase/schema.sql`](supabase/schema.sql) in SQL Editor.
  3. Copy `.env.example` to `.env.local` and fill your project values.
  4. Follow [`supabase/SETUP.md`](supabase/SETUP.md).
